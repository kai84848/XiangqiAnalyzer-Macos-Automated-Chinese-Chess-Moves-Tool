# 象棋窗口自动对弈

自动对弈已经内置在 **棋析** 的 Qt 界面中。窗口选择、窗口截图、棋盘识别、最佳着法计算和鼠标点击均由应用原生完成，不需要 Python、终端或外置脚本。

除了微信电脑版的天天象棋，也可以选择浏览器中的网页版象棋或其他象棋应用窗口。前提是棋子样式能被现有本地识别模型正确辨认，并且游戏支持“先点棋子、再点目标交叉点”的操作方式。

## 首次使用

1. 构建并打开 `XiangqiAnalyzer.app`。
2. 打开要使用的象棋游戏窗口，完整显示棋盘。
3. 点击棋析工具栏最后的 **“自动对弈”**。
4. 如果 macOS 请求权限，请在“系统设置 → 隐私与安全性”中给 **棋析** 授予：
   - **屏幕录制与系统录音**：列出窗口、显示缩略图并读取棋盘。
   - **辅助功能**：切换窗口并点击棋子。

这里授权的是棋析应用本身，不是终端。屏幕录制权限变更后，按系统提示重新打开棋析。

## 选择对弈窗口

点击“自动对弈”后，会出现类似会议投屏的窗口选择界面：

- 以缩略图显示当前可共享的应用窗口。
- 单击窗口卡片进行选择，双击可直接使用该窗口。
- 打开新的游戏窗口后，点击 **“刷新”** 更新列表。
- 点击 **“使用此窗口”** 进入对局设置。

应用通过 macOS ScreenCaptureKit 只截取所选窗口，不依赖天天象棋的进程名称。棋析切回前台时，也不会把其他窗口误认为对弈画面。

## 开始对弈

在对局设置中确认：

- **己方执子**：执红或执黑。
- **开始方式**：
  - “从当前局面继续（轮到己方）”：接续已经开始的棋局。启动时必须确实轮到己方，不要在对方思考时启动。
  - “从初始局面开始”：要求棋盘尚未走子；执黑时会等待对方先走。
- **棋盘方向**：红方在下方或上方，必须与游戏实际显示一致。
- **每手思考**：200–60000 毫秒，默认 1000 毫秒。

点击 **“开始对弈”**。应用会激活所选窗口，识别棋盘四角和棋子、计算走法并点击起止点，同时把局面同步到棋析主棋盘。

四角定位直接来自本地识别模型，无需手工测量棋盘坐标。点击位置使用四角透视映射和窗口当前位置、尺寸计算，因此窗口移动或缩放后会自动适配。

运行中工具栏按钮变为 **“停止对弈”**，再次点击即可停止；关闭棋析也会停止自动对弈。

## 安全校验与异常处理

- YOLO 棋子检测决定主要占用和棋子位置，整盘分类与同盘/固定模板用于交叉复核；重复检测、类别冲突和空格占用争议都会进入快速重拍。
- 初始化和每个新局面都必须连续两帧完全一致；低置信或识别失败帧会打断稳定计数，走子动画中的单帧不会被接受。
- 只接受符合上一局面一步合法走法的棋盘变化，不会把任意识别差异当成对手着法，也不会为了匹配合法走法自动改动棋子。
- 己方点击后会核对预期落盘局面。
- 棋子识别置信度不足、棋盘变化异常或点击未生效时，不会继续盲目走棋；应用会缩短间隔快速重拍，持续低置信、无法稳定或持续不合法时会停止并在 Qt 中显示具体原因。
- 所选窗口关闭、无法计算四角点击坐标、45 秒没有任何合法棋局进展或对局结束时都会停止；识别异常使用上述更短的复核路径，不再统一等待 45 秒。

## 当前限制

- 需要 macOS 14 或更高版本；目前不支持 Windows 或手机投屏。
- 棋盘必须完整显示，不能被裁剪；特殊皮肤、强烈透视、棋子遮挡和走子动画可能降低识别率。
- 网页或其他应用需要支持点击起点、再点击终点的走棋方式；拖放式操作暂不支持。
- 如果棋子皮肤与天天象棋差异过大，可能无法正确识别。这不影响选择窗口，但会阻止自动走棋。

## 可选的外部参考工具

仓库仍保留 `tools/tiantian_autoplay.py` 和 `autoplay_helper`，供早期开发调试使用。它们不是 Qt 自动对弈按钮的运行依赖，正常使用无需构建或运行这些工具。
